
# Baymax

An app inspired by the children’s movie Baymax. It helps you track your water intake and step count, provides quotes, thoughts, and jokes, and also guides you in meditation.

This project was created for learning purposes, with the main focus on implementing push notifications based on user actions (e.g., when the user clicks the drink water icon). It also includes setting up an FCM server with Node.js to send notifications either to specific devices or as broadcasts, along with scheduled daily reminders for water intake and sleep.

Other concepts explored in this app include text-to-speech, sound playback, state management with Zustand, persistent storage using MMKV, step tracking via device sensors, and animations.
